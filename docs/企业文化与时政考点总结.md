# 企业文化与时政 · 考点总结与 2026 预测

## 一、先看清这类题在考什么

| 主题 | 题数 | 典型问法 |
| --- | --- | --- |
| 公司战略 | 52 | "四轮驱动指什么""以什么为主线" |
| 企业文化/价值观 | 44 | "企业使命是""理念体系由几部分构成" |
| 5G/网络 | 41 | "4G制式""5G-A""基站数" |
| 党建/央企 | 19 | "国资委考核""政治责任" |
| 行业常识 | 16 | "客服热线""运营商排名" |
| AI/新质生产力 | 15 | "九天大模型""AI+行动" |
| 算力/云 | 14 | "算力网络""东数西算""移动云" |
| 时政/政策 | 14 | "十四五""二十大""东数西算" |
| 乡村振兴/民生 | 6 | "网络+乡村振兴" |

三种题型：**填空型**（补数字/名称）、**匹配型**（属于/不属于）、**内涵型**（某句话怎么理解）。

**最关键的一条规律**：

> **底座表述常年不变，数字和"最新提法"每年换。**
> 「正德厚生 臻于至善」考了 8 年没变过；但"营收多少亿""5G 基站多少万个""世界 500 强第几名"每年都要换。

所以复习分两层：**背死的**（文化、战略名词表）+ **考前一周去核对的**（数字、最新提法）。

## 二、底座：不随年份变的部分（必须背死）

### 2.1 企业概况

| 项 | 内容 |
| --- | --- |
| 全称 | China Mobile Communications Corporation（CMCC） |
| 成立 | 2000 年组建，国有重要骨干中央企业 |
| 上市 | 2022 年 1 月回归 **A 股**（红筹公司回归 A 股第一股） |
| 客服热线 | **10086**（联通 10010、电信 10000，常一起考） |
| 规模地位 | **三个全球第一**：网络规模、客户规模、收入规模 |
| 领先项 | **四个全球领先**：创新能力、品牌价值、公司市值、盈利水平 |

### 2.2 企业文化（年年考，绝不能错）

| 项 | 内容 |
| --- | --- |
| 核心价值观 | **正德厚生，臻于至善** |
| 企业使命 | **创无限通信世界，做信息社会栋梁** |
| 理念体系构成 | **核心价值观 + 使命 + 愿景**（三部分） |
| "臻于至善" | 是一种**不断完善、不断超越**的状态 |
| 商业主品牌 | **"和"** |

> 真题对照：2020 Q92 问"理念体系由哪三部分构成"，答案是"核心价值观、使命、愿景"；
> 2017 Q92 问"企业使命"，答案是"创无限通信世界，做信息社会栋梁"；
> 2023 Q97 问"臻于至善是什么状态"，答案是"不断完善、不断超越"。
> **这三题几乎每年换皮重考。**

## 三、逐年主线：为什么老卷答案会"过期"

| 年份 | 当年的新提法 |
| --- | --- |
| 2017–2018 | 基础事实（制式、品牌、客服热线）、"大连接"战略、品牌"和" |
| 2019 | 4G 制式、取消漫游费、4G 品牌标志 |
| 2020 | 5G 牌照发放、四轮驱动、5G 基站数、世界 500 强排名 |
| 2022 | 数智化转型主线、CHBN 全向发力、算力网络、三大品牌焕新 |
| 2023 | 力量大厦、人才体系、"两和"、A 股上市、咪咕 |
| 2024 | 5G-A 演进、收入破万亿、超级工程、"三个全球第一"表述固化 |
| 2025 | **三个计划**、破风 8676 芯片入选"国之重器"、国资委考核连年 A 级、移动爱家 + 九天大模型 |

**用法**：做旧卷子时按"当年口径"答；做新卷子时，凡是上面表里出现过的提法，一律用**最新一版**。

## 四、真题示例（带答案，这几道最能代表出题风格）

| 题 | 问法 | 答案 |
| --- | --- | --- |
| 2020 Q92 | 企业文化理念体系由哪三部分构成 | 核心价值观、使命、愿景 |
| 2020 Q99 | 四轮驱动战略的内涵 | 个人、家庭、政企、新兴市场 |
| 2022 Q98 | 以什么为主线，加快"三转"… | 推进数智化转型、实现高质量发展 |
| 2024 Q99 | 三个全球第一 / 四个全球领先 | 网络·客户·收入规模；创新·品牌·市值·盈利 |
| 2025 Q96 | "三个计划"指哪三个 | "AI+"行动、"BASIC6"科创、"两个新型"升级 |
| 2025 Q97 | 2024 全球合作伙伴大会发布什么 | 移动爱家"五新"品牌升级 + 九天普智多模态基座大模型 |
| 2025 Q98 | 破风 8676 芯片入选什么 | 国之重器 |
| 2023 Q97 | "臻于至善"是什么状态 | 不断完善、不断超越 |

看出规律了吗——**除了常识题，答案基本都是"官方原话"**，没有推论空间。所以这类题不靠理解，靠**认原句**。

## 五、2026 预测：最可能考的 15 个点

按"出现频次 × 近年趋势"排序。每条给了**为什么押**和**要背什么**。

### 高频必考区（近三年每年都碰）

**1. 世界一流信息服务科技创新公司**
近三年出现 15 次，是所有战略题的总纲。要背：这是**目标定位**，不是口号；配套说法是"全面建设"。

**2. 三个计划："AI+"行动计划、"BASIC6"科创计划、"两个新型"升级计划**
2025 卷刚考，属于最新框架，命题人偏爱"三个计划分别是什么"这种填空。

**3. 两个新型**
新型信息基础设施 + 新型信息服务体系。常和"升级计划"连考，注意"两个新型"升级计划里具体升级的是这两项。

**4. 三个全球第一 / 四个全球领先**
2024 卷考过原文，属于"换皮重考"的典型：网络/客户/收入规模 + 创新/品牌/市值/盈利。

**5. 文化三件套**
价值观「正德厚生 臻于至善」、使命「创无限通信世界 做信息社会栋梁」、理念体系三部分。
**几乎可以当送分题准备**，但每年都有人栽在"使命"和"愿景"张冠李戴。

**6. CHBN 四轮驱动**
个人、家庭、政企、新兴四大市场。常与"全向发力""四轮驱动"一起出现。

**7. 发展主线："推进数智化转型、实现高质量发展"**
陷阱在**"数智化"vs"数字化"**——2022 Q98 四个选项就是在这两个词上做区分。

### 趋势上升区（近两年新出现，今年大概率延续）

**8. 5G-A（5G-Advanced）**
2024 卷明确考"5G 正加速向 5G-A 演进"。要背：5G-A 是 5G 向 6G 的过渡阶段，公司定位是"主力军"。

**9. "AI+"与九天大模型**
2024 合作伙伴大会发布"九天"普智多模态基座大模型 + 30 款行业大模型。AI 是当下第一叙事，几乎必考。

**10. 算力网络 / 东数西算 / 移动云**
算力是运营商第二增长曲线，"信息高铁""云网云边云数协同"是常用原话。

**11. 新质生产力**
近两年出现 4 次且逐年在涨。要能把它和"AI+""算力""科技创新"挂上钩。

**12. 6G 与标准话语权**
2024 卷考过"牵头完成 6G 标准"。常以"牵头/主导/全球首个"这类表述出现。

### 稳健押注区（隔年出现，性价比高）

**13. 品牌体系**
三大品牌（全球通、动感地带、神州行）焕新 + "和" + 移动爱家 + 咪咕。
考法多为"下列哪个不是中国移动的品牌"。

**14. 国资委考核 / 央企责任**
"连续多年获评 A 级""政治责任、经济责任、社会责任"。属于数字题，**考前必须核对最新年数**。

**15. 乡村振兴 / ESG / 绿色低碳**
出现频次不高但极稳（几乎每套都有 1 道），常与"数字乡村""网络+"搭配。

## 六、考前一周怎么保持口径最新

这类题**唯一会翻车的地方是背了去年的数字**。建议考前集中核对四个来源：

1. **官网新闻**（10086.cn → 关于我们 → 集团新闻）：工作会通稿、合作伙伴大会、MWC 演讲
2. **年度业绩报告**：营收、净利润、客户数、5G 基站数
3. **《财富》世界 500 强**最新排名
4. **国资委经营业绩考核**结果（A 级连续年数）

必核的三个数：**营收（亿元）、5G 基站（万个）、世界 500 强排名**。

## 附：一句话记忆法

> **文化记三句**：正德厚生臻于至善（价值观）、创无限通信世界做信息社会栋梁（使命）、核心价值+使命+愿景（体系）。
> **战略记三层**：世界一流信息服务科技创新公司（目标）→ 力量大厦/CHBN（框架）→ 三个计划·两个新型（抓手）。
> **数字记三个**：营收、基站、排名——考前一周再背，别提前背。
